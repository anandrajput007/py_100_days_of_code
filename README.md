# Day 2 — Input & Variables

**Files:** `DAY_002/02_input_and_vars.py`

**Summary:**
- Reading input from the user (`input()`)
- Storing values in variables and measuring lengths
- Small example using strings and integer conversion

**Example**

```py
# DAY_002/02_input_and_vars.py
name = input("Enter your name: ")
print(f"Hello, {name}! Your name has {len(name)} characters.")
```

**Notes:** Demonstrates interacting with the user and basic string operations. Good next step after printing.
